# AGENTS.md

## Mandatory project rule

Read `bel_zamora_website_plan.md` before changing code.

## Before editing

1. Inspect Git status and recent commits.
2. Inspect the relevant code, tests, configuration, and documentation.
3. Read the active phase and latest update in the plan.
4. Confirm the task is unblocked and in scope.
5. Identify expected files and validation commands.
6. Search for existing or duplicate implementations.

## During implementation

- Keep the change focused.
- Follow Laravel, Vue, TypeScript, Inertia, Filament, and project conventions.
- Enforce validation and authorization on the server.
- Protect personal and inquiry data.
- Preserve accessibility, responsiveness, performance, and SEO.
- Do not add secrets or production data.
- Do not remove working behavior without documenting the reason.
- Add or update tests.

## Before ending

1. Run all relevant validation commands listed in root [`AGENTS.md`](../AGENTS.md).
2. Record exact results.
3. Update `bel_zamora_website_plan.md`.
4. Update all affected documentation.
5. State unresolved issues and blockers.
6. Provide the exact next task and a copy-ready next-session prompt.

Never mark a task complete without implementation, integration, validation, documentation, and acceptance evidence.
